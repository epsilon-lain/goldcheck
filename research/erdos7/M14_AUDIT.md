# Milestone 14 conditioning audit

This note audits the only non-arithmetic step left explicitly open in
`certificates/11486475.md`: the Clique-Shearer conditioning argument.

## 1. Source theorem actually needed

Hough–Nielsen, *Covering systems with restricted divisibility*, Appendix C,
Theorem 16 (Clique Shearer Theorem), treats a dependency graph whose vertices
are nonempty subsets of a clique-coordinate set and where two vertices are
adjacent exactly when the corresponding subsets intersect.  It gives both an
avoidance lower bound and a relative conditional lower bound in terms of the
independent-set polynomial, provided all clique-coordinate polynomials are
positive.

The proof uses the event probabilities only through upper bounds.  Therefore
the identical induction remains valid if every true probability `P(A_S)` is
replaced throughout by any number `q_S >= P(A_S)`, provided the corresponding
coordinate polynomials are positive.  This is exactly our situation: `q_S` is
the union-bound charge of the grouped congruences in one fixed 27-fibre.

## 2. Why the support graph is valid

Inside a fixed surviving residue `r mod 27`, the ambient probability space is
uniform on `Z/MZ`, with

`M = 5^2 * 7 * 11 * 13 * 17`.

The grouped event `A_S(r)` is measurable only with respect to the prime-power
CRT coordinates indexed by `S`.  Consequently, if `S` and `T` are disjoint,
`A_S(r)` is independent of the sigma-algebra generated by events supported in
`T`.  Thus support intersection is a valid dependency graph, exactly of the
Clique-Shearer form.

## 3. Close the downward-box issue exactly

For the 15 supports not containing 5, M14 used the box

`b_T <= q_T <= 4 b_T`,  `T subset {7,11,13,17}`, `T != empty`.

Rather than relying only on an abstract downward-closure statement, the new
independent verifier `solver/m14_shearer_audit.py` checks the whole box.
Every coordinate polynomial `rho_C` is multi-affine, so its minimum is attained
at a box corner.  Exhausting all `2^15 = 32768` corners gives

`min_{C,q} rho_C(q) = 941/17017 > 0`.

Hence every possible non-5 charge vector occurring in a fibre satisfies the
hypotheses needed for the relative Clique-Shearer bound.

## 4. One-coordinate completion lemma

Let `J={7,11,13,17}` and let `B` be the event that all grouped events with
support contained in `J` are avoided.  For `T subset J`, write

`E_T = A_{ {5} union T }`.

Because `E_T` is independent of all non-5 events supported inside `J\T`,

`P(E_T intersect B) <= P(E_T) P(B_{J\T}) <= q_{5T} P(B_{J\T})`.

The relative Clique-Shearer bound for the non-5 system gives

`P(B) / P(B_{J\T}) >= rho_J(q^0) / rho_{J\T}(q^0)`.

Therefore

`P(E_T | B) <= q_{5T} rho_{J\T}(q^0) / rho_J(q^0)`.

A union bound over the 16 possible `T` shows that, conditioned on `B`, the
5-containing events fail to cover whenever

`rho_J(q^0) - sum_T q_{5T} rho_{J\T}(q^0) > 0`.

But an independent support family contains at most one support involving the
5-coordinate.  Hence the left-hand side is exactly the full five-coordinate
independent-set polynomial `rho(q)`.  The new verifier separately checks this
split identity against a direct five-coordinate recurrence.

Thus the implication used in M14 is valid:

> if `rho(q(r)) > 0` for a surviving fibre, that fibre contains an uncovered
> point.

## 5. Consequence for the seed certificate

The independent arithmetic certificate already proves

`sum_{r in 14 fibres} rho(q(r)) >= 86563/425425 > 0`.

Therefore at least one selected surviving fibre has `rho(q(r))>0`.  By the
conditioning lemma above, that fibre is not covered.  This contradicts a
saturated covering of

`11486475 = 3^3 * 5^2 * 7 * 11 * 13 * 17`.
