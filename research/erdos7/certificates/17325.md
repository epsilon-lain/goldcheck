# Certificate: `17325` is not a covering number

`17325 = 3^2 · 5^2 · 7 · 11`.

```
δ(1155)  >= 296                                         [square-free CRT/Hall bound]
δ(5775)  >= 5*δ(1155) - σ(231)  = 1480 - 384  = 1096    [deficiency recurrence, p=5]
δ(17325) >= 3*δ(5775) - σ(1925) = 3288 - 2976 = 312     [deficiency recurrence, p=3]
```

`σ(231) = (1+3)(1+7)(1+11) = 384`,
`σ(1925) = (1+5+25)(1+7)(1+11) = 2976`.

Therefore `δ(17325) ≥ 312 > 0`, so `17325` is not a covering number.
