# Certificate: `12285` is not a covering number

`12285 = 3^3 · 5 · 7 · 13`.

```
δ(1365)  >= 366                                        [square-free CRT/Hall bound]
δ(4095)  >= 3*δ(1365) - σ(455)  = 1098 - 672 = 426     [deficiency recurrence, p=3]
δ(12285) >= 3*δ(4095) - σ(455)  = 1278 - 672 = 606     [deficiency recurrence, p=3]
```

`σ(455) = (1+5)(1+7)(1+13) = 672`.

Therefore `δ(12285) ≥ 606 > 0`, so `12285` is not a covering number.
