# Certificate: `51975` is not a covering number (full divisor-set bound)

`51975 = 3^3 · 5^2 · 7 · 11`.

McNew–Setty Lemma 4.10 / equation (10) applied to the **full** divisor set
`D_{>1}(51975)` gives

    r(51975)/51975 ≤ R(51975) = 9536/10395 < 1,

where `R(n)` is the prime-power support form

    R(n) = Σ_{∅≠U⊆supp(n)} C_|U| ∏_{i∈U} x_i,
    x_i = (1 − p_i^{-v_p(n)})/(p_i−1),   C_m = Σ_{t=1..m} (−1)^{t+1} S2(m,t).

For `51975`:

    x_3 = 13/27,  x_5 = 6/25,  x_7 = 1/7,  x_11 = 1/11,
    R = e_1 − e_3 − e_4 = 9536/10395.

Therefore

    δ(51975) = 51975 − r(51975)
              ≥ 51975·(1 − 9536/10395)
              = 51975 · 859/10395
              = 4295.

Since `δ(51975) ≥ 4295 > 0`, the number `51975` is **not** a covering number.

Independent verification: `solver/full_bound.py` computes the same bound by the
support form *and* by the direct divisor-sum form of equation (10); both agree
exactly (`test_full_bound.py`).
