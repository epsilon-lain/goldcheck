# 11486475 — Milestone 14 Clique-Shearer certificate candidate

Target:
\[
N_* = 11486475 = 3^3\cdot 5^2\cdot 7\cdot 11\cdot 13\cdot 17
      =27M,\qquad M=425425.
\]

This note records a self-contained finite certificate discovered in Milestone 14.
The arithmetic is verified exactly by `solver/m14_clique_shearer.py` using
`fractions.Fraction`; no floating-point optimizer is trusted by the verifier.

**Status caution.** This is a finite exclusion of one six-prime seed, not a
solution of the odd distinct covering-system problem. The Clique-Shearer
conditioning step should be independently audited before any novelty/publication
claim.

## 1. Saturation is WLOG for a nonexistence proof

Suppose a valid distinct covering family uses only some divisors `d>1` of
`N_*`. For every missing divisor, add one arbitrary residue class modulo that
divisor. The moduli remain distinct and the covered set can only grow.
Therefore, if any divisor-modulus covering exists, one exists using **every**
divisor `d>1` exactly once.

This justifies assuming the moduli `3,9,27` and, for each `m|M`,
`m,3m,9m,27m` (where the modulus is `>1`) are present.

## 2. Fourteen surviving 3-adic fibres

The pure classes modulo `3,9,27` cover at most `9+3+1=13` residues modulo
`27`. Hence at least 14 residues `r mod 27` survive. Select any 14 of them.

Fix `m|M, m>1`. In a surviving fibre `r mod 27`, the four moduli
`m,3m,9m,27m` induce at most
\[
 k_m(r)=1+
 {\bf1}_{r\equiv c_{1,m}\pmod3}+
 {\bf1}_{r\equiv c_{2,m}\pmod9}+
 {\bf1}_{r=c_{3,m}}
\]
residue classes modulo `m`. Duplicates only reduce the true union.

For any 14 distinct residues modulo 27,
\[
 \sum_r k_m(r)\le 14+9+3+1=27.
\]

## 3. Group by square-free support

Encode the primes `(5,7,11,13,17)` by bits `0,...,4`. For every nonempty
support `S`, let `A_S(r)` be the union, inside the fixed 27-fibre, of all
induced congruences whose exact `M`-modulus has square-free support `S`.

Set
\[
 q_S(r)=\sum_{\substack{m\mid M\\\mathrm{sqf}(m)=S}}\frac{k_m(r)}m.
\]
Then `P(A_S(r)) <= q_S(r)` by the union bound. Put
\[
 x_5=\frac15+\frac1{25}=\frac6{25},\qquad
 x_7=\frac17,\ x_{11}=\frac1{11},\ x_{13}=\frac1{13},\ x_{17}=\frac1{17},
\]
and
\[
 b_S=\prod_{p\in S}x_p.
\]
Saturation and `1 <= k_m(r) <= 4` give
\[
 b_S\le q_S(r)\le4b_S,
\]
while the 14-fibre budget gives
\[
 \sum_r q_S(r)\le27b_S.
\]

Events with disjoint supports are independent by CRT, so support intersection is
a valid dependency graph.

## 4. Clique-Shearer reduction

For support variables `q_S`, define the independent-set polynomial
\[
 \rho(q)=1-\sum_Sq_S+
 \sum_{S_1\cap S_2=\varnothing}q_{S_1}q_{S_2}-\cdots.
\]

First consider only supports not containing 5, on
`J={7,11,13,17}`. At the pointwise worst vector `q_T=4b_T`, the 16
Clique-Shearer coordinate polynomials are, in coordinate-mask order,

```text
0:1
2:3/7       4:7/11       6:17/77
8:9/13      10:23/91     12:59/143    14:109/1001
16:13/17    18:5/17      20:87/187    22:177/1309
24:113/221  26:19/119    28:699/2431  30:941/17017
```

and are all positive. The same Clique-Shearer induction works with event
probabilities bounded above by these `q_T`, so every smaller non-5 vector is
also certified and the relative conditional bound is available.

Now write a support containing 5 as `{5} union T`, `T subset J`. Condition on
avoiding all non-5 events. The event `A_{5 union T}` is independent of all
non-5 events supported inside `J minus T`. The relative Clique-Shearer bound
and a union bound over the 16 supports containing 5 show that the fibre remains
nonempty whenever
\[
 \rho_J(q^0)-\sum_{T\subseteq J}q_{\{5\}\cup T}
                 \rho_{J\setminus T}(q^0)>0.
\]
By the independent-set recurrence when coordinate 5 is added, the left side is
exactly the full `rho(q)`.

Thus **`rho(q(r))>0` is sufficient to leave the fibre uncovered**.

## 6. Independent exact verifier for the affine inequality

The weights may have been discovered numerically, but the verifier does not use
the optimizer.

The function
\[
 F(q)=\rho(q)+\sum_S\lambda_Sq_S
\]
is multi-affine, so its minimum on the box occurs at a corner. Split the
variables into 15 supports not containing 5 and 16 supports containing 5.

For each of the `2^15=32768` non-5 corners, compute all `rho_C`, `C subset J`.
Once those are fixed,
\[
 F=
 \rho_J+\sum_{S\subseteq J,\ S\ne\varnothing}\lambda_Sq_S+
 \sum_{T\subseteq J}
 \bigl(\lambda_{\{5\}\cup T}-\rho_{J\setminus T}\bigr)
 q_{\{5\}\cup T}.
\]
Thus each 5-containing variable is minimized independently at one endpoint.
Exact enumeration gives
\[
 \min F=\frac{8134}{12155}=C.
\]
The minimizing corner has all non-5 variables at their lower endpoints and only
masks `1,9,17` at the upper endpoint among supports containing 5.
