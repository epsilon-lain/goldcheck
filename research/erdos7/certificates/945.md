# Certificate: `945` is not a covering number

`945 = 3^3 · 5 · 7`.

```
δ(105)  >= 35                                        [square-free CRT/Hall bound]
δ(315)  >= 3*δ(105) - σ(35)  = 105 - 48  = 57        [deficiency recurrence, p=3]
δ(945)  >= 3*δ(315) - σ(35)  = 171 - 48  = 123       [deficiency recurrence, p=3]
```

`σ(35) = (1+5)(1+7) = 48`.

Therefore `δ(945) ≥ 123 > 0`, so `945` is not a covering number.
