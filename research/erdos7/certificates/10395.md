# Certificate: `10395` is not a covering number

`10395 = 3^3 · 5 · 7 · 11`.

```
δ(1155)  >= 296                                        [square-free CRT/Hall bound]
δ(3465)  >= 3*δ(1155) - σ(385)  = 888 - 576  = 312     [deficiency recurrence, p=3]
δ(10395) >= 3*δ(3465) - σ(385)  = 936 - 576  = 360     [deficiency recurrence, p=3]
```

`σ(385) = (1+5)(1+7)(1+11) = 576`.

Therefore `δ(10395) ≥ 360 > 0`, so `10395` is not a covering number.
